# Extension Location and Details

The Agentic AI extension is in ‘AI’ ecosystem and in the ‘Agentic AI’ domain.

The Details UI panel in the Extension UI displays the extension details such as:

* Primary Domain
* Version
* Invoker ID
* Extension Base URL
